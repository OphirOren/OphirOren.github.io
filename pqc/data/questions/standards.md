# Domain: Post-Quantum Cryptographic Standards and Guidelines

### Q1. Which mapping is correct?
A. ML-KEM — signature
B. ML-DSA — key encapsulation
C. SLH-DSA — hash-based signature
D. QKD — lattice-based KEM
**Answer: C**
**Explanation:** SLH-DSA (SPHINCS+) is a stateless hash-based signature standard. ML-KEM is for key establishment; ML-DSA is for signatures.

### Q2. A team needs a finalized NIST signature standard that is not lattice-based. Which fits best?
A. ML-KEM
B. SLH-DSA
C. HQC
D. BB84
**Answer: B**
**Explanation:** SLH-DSA is a finalized hash-based signature. HQC is a KEM still progressing through standardization; ML-KEM is not a signature.
