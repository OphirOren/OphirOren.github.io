# Domain: Quantum-Safe Migration Strategy

### Q1. What should usually be the first step in an enterprise PQC program?
A. Immediate replacement of all PKI
B. Buying QKD for every site
C. Inventory of cryptographic uses linked to assets and data
D. Direct cutover to FN-DSA
**Answer: C**
**Explanation:** Discovery and cryptographic inventory (often via CBOM-style mapping) come before remediation and wide rollout.

### Q2. A new system must interoperate with legacy clients. Which migration approach fits better?
A. Pure cutover with no fallback
B. Parallel or backward-compatible migration with controlled negotiation
C. Removing authentication
D. Using QKD over the public internet only
**Answer: B**
**Explanation:** Backward-compatible or parallel migration preserves interoperability while PQC capability is introduced safely.
