# Domain: Practical Implementation of Quantum Security

### Q1. What is the primary role of a KEM?
A. Sign a document
B. Create or encapsulate a shared secret for key establishment
C. Hash a password
D. Manage certificate revocation
**Answer: B**
**Explanation:** A key encapsulation mechanism establishes shared secrets; signatures serve authentication/integrity, not key encapsulation.

### Q2. Which is a clear sign of good crypto-agility?
A. Algorithms hard-coded in every application
B. An abstraction layer and policy that allow suite replacement and testing
C. One shared key for all services
D. Dependence on a single vendor with no roadmap
**Answer: B**
**Explanation:** Crypto-agility means algorithms, parameters, protocols, certificates, and providers can change without destructive redesign.
